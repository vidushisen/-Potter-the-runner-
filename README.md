🏰 Hogwarts Dash - Harry Potter 3D Runner
HTML5CSS3JavaScriptThree.jsWeb Audio API

Hogwarts Dash is an immersive, feature-packed 3D endless runner game built with Three.js, Vanilla CSS, and Web Audio API. Sprint through the gothic corridors of Hogwarts, leap over Potions Cauldrons, glide on Firebolt Broomsticks, catch Golden Snitches, and escape Argus Filch & Mrs. Norris!

🌟 Key Features
🏰 3D Realistic Hogwarts Castle: Detailed cobble corridors, vaulted arches, glowing stained glass windows, torch sconces, and Hogwarts Express tracks.
🧹 Firebolt Broomstick Sky Flight: Take flight into the sky lane above all obstacles with smooth automatic landing back onto the tracks!
⚡ Golden Snitches & Bertie Bott's Beans: Catch rare Quidditch Snitches for +500 BONUS POINTS and collect colorful beans.
🐱 Argus Filch & Mrs. Norris Pursuer: Filch and his cat close in whenever you stumble on obstacles!
🔮 Diagon Alley Shop: Earn Snitches to unlock Hermione Granger and Ron Weasley, and upgrade power-up durations!
🏃 Interactive Speed Options: Choose between 🐢 RELAXED (16 m/s), ⚡ NORMAL (22 m/s), or 🚀 NIMBUS 2000 (28 m/s) directly from the Main Menu.
🎶 Authentic Hedwig's Theme Soundtrack: Polyphonic John Williams film soundtrack synthesized using Web Audio API.
🕹️ Controls Guide
Action	Keyboard Key	Screen Click / Touch
Move Left	A or ← Left Arrow	Click Left Side / Swipe Left
Move Right	D or → Right Arrow	Click Right Side / Swipe Right
Jump	W or ↑ Up Arrow or Space	Click Center / Swipe Up
Slide	S or ↓ Down Arrow or Shift	Swipe Down
Cast Spell	E or F or UI Button	Click Spell Button
💻 Tech Stack & Architecture
Renderer: Three.js WebGL Engine with BasicShadowMap shadow rendering
Audio: Web Audio API Synthesizer with memory node disconnections
Styling: Vanilla CSS parchment card design system with gold foil glows
Storage: LocalStorage API for saving high scores & unlocked wizards
