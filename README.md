<h3 align="center">⚡ About The Game ⚡</h3>

<br/>

**Potter The Runner** is an enchanting 2D endless flight and runner game inspired by the Wizarding World, built entirely with native web technologies on HTML5 Canvas.

Mount your Firebolt broomstick and take flight across the skies of Hogwarts. Dodge sinister Dementors, weave through dangerous obstacles, collect magical bonuses, and chase the elusive Golden Snitch in an exhilarating test of wizarding reflexes!

<br/>

---

<h3 align="center">🪄 Key Features 🪄</h3>

<br/>

- 🧹 Fluid Broomstick Flight Controls:  Responsive keyboard controls for swift vertical dives and soaring climbs.
- 🧙‍♂️ Iconic Magical Elements:  Encounter roaming Dementors, enchanted obstacles, and glowing score multipliers.
- 🏆 Snitch Hunt & High Scores:  Push your flying stamina to set new distance records and capture rare items.
- 🎮 Smooth 60 FPS Canvas Engine:  Lightweight physics engine with zero lag and crisp retro-arcade rendering.
- 🚀 Zero Installation Required:  Pure vanilla JavaScript that runs instantly in any modern web browser.
